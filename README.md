# Ur Travel Bestie website

This folder is ready to upload to GitHub Pages.

## Included
- `index.html` — the website
- `style.css` — responsive styling
- `assets/ur-travel-bestie-logo.jpg` — the logo you supplied
- `assets/how-i-book-flights.mp4` — A narrated MP4 guide is included in assets/how-i-book-flights.mp4.

## Website link
The site links to:
https://urtravelbestie.co.za

## Put it on GitHub
1. Create a new GitHub repository.
2. Upload **everything inside this folder** (not the ZIP file).
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will give you your public website address.

## Change the video
Replace `assets/how-i-book-flights.mp4` with your own video and keep the same filename.
